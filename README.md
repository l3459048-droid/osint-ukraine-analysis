# OSINT Ukraine Analysis — local-first v0.4

Локальная система для обработки, индексации и поиска по коллекции OSINT-документов. Основной сценарий больше не требует Google Drive: документы могут находиться в любой папке на ПК, а ежедневная работа выполняется из локального Web UI.

## Что уже работает

```text
локальная папка
      ↓
PDF / DOCX / TXT / MD
      ↓
извлечение текста + опциональный OCR
      ↓
SHA-256 / дедупликация / SQLite
      ↓
тематическая классификация
      ↓
page-aware chunks
      ↓
lexical / multilingual semantic search
      ↓
локальный Web UI на http://127.0.0.1:8080
```

v0.4 делает основной рабочий цикл UI-first. На главной странице оставлены только три действия:

- **Scan** — найти новые/изменённые документы и обработать их;
- **Build index** — достроить semantic embeddings;
- **Refresh** — перечитать состояние интерфейса.

Долгие операции выполняются в фоне. Интерфейс показывает одну компактную строку состояния и прогресс, а последние результаты и ошибки спрятаны в сворачиваемом блоке **Activity**. Одновременно может выполняться только одна тяжёлая операция, чтобы пользователь случайно не запустил два сканирования или индексации поверх одной базы.

Исходные документы не изменяются и не удаляются.

## Быстрый запуск на Windows

```powershell
git clone https://github.com/l3459048-droid/osint-ukraine-analysis.git
cd osint-ukraine-analysis
git checkout local-ingestion-v1

python -m venv .venv
.venv\Scripts\activate
pip install -e ".[all]"

osint-local init
```

Один раз укажите папки в `config.json`, например:

```json
{
  "input_dir": "D:/OSINT/Documents",
  "workspace_dir": "D:/OSINT/AnalysisData"
}
```

После этого можно пользоваться почти без терминала: дважды запустите `start_local.bat`, браузер откроет локальный интерфейс, затем нажмите **Scan**. Для semantic search после добавления документов нажмите **Build index**.

Адрес по умолчанию:

```text
http://127.0.0.1:8080
```

## Минималистичный Web UI

Главный экран содержит только то, что нужно постоянно:

- состояние библиотеки и прогресс текущей операции;
- `Scan`, `Build index`, `Refresh`;
- четыре короткие метрики;
- строку поиска;
- категории и последние документы.

Второстепенная информация не занимает экран: `Activity` раскрывается только при необходимости и показывает последнее действие и недавние ошибки обработки.

Поиск, список документов и карточка документа остались отдельными спокойными экранами. Для PDF результаты по-прежнему могут открывать исходник на соответствующей странице (`#page=N`).

## OCR и semantic search

Для полного локального варианта удобнее сразу установить всё:

```powershell
pip install -e ".[all]"
```

Отдельно доступны:

```powershell
pip install -e ".[ocr]"
pip install -e ".[search]"
```

Semantic model по умолчанию — multilingual Sentence Transformers. При первой установке модель может быть скачана, после кеширования поиск работает локально. В `search.model` можно указать путь к заранее скачанной модели для полностью offline-режима.

Если semantic-зависимости не установлены, **Build index** в UI отключён и обычный lexical search продолжает работать.

## CLI остаётся доступным

UI заменяет повседневные команды, но CLI не удалён:

```powershell
osint-local init
osint-local doctor
osint-local scan
osint-local watch
osint-local index
osint-local search "FPV drones"
osint-local serve
osint-local status
```

Это удобно для диагностики, скриптов и автоматизации.

## Безопасность локального интерфейса

По умолчанию Web UI слушает только `127.0.0.1`. Привязка к внешнему интерфейсу требует явного `--allow-network`.

Изменяющие действия Web UI выполняются только через POST и требуют сессионный CSRF-токен. API поиска/статистики остаётся read-only.

## API

```text
GET /api/stats
GET /api/search?q=fpv&mode=lexical&limit=10
GET /api/activity
```

## Обновление с v0.1–v0.3

SQLite-база совместима и мигрируется автоматически. Новых разрушительных миграций для v0.4 нет. Чанки и embeddings из v0.2/v0.3 сохраняются.
